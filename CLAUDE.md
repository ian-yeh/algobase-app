# CLAUDE.md

Algobase: speedcubing timer + training app. React 19 + Vite frontend, Convex backend (data, auth, live queries). npm workspaces monorepo.

## Layout
- `apps/web/` - Vite app (`@algobase/web`). `src/pages`, `src/features/<feature>`, `src/components`, `src/lib` (pure utils), `src/stores` (Zustand: `authStore`, `themeStore`), `router.tsx`, `main.tsx`.
- `packages/convex/` - Convex functions (`convex.json` points here). Modules: `auth`, `solve`, `user`, `algLists`, `competitions`. Tables in `schema.ts`: users, passwords, solves, userStats, algLists, algEntries, competitionCache.
- `packages/convex/_generated/` - generated by `convex dev`. Never hand-edit.
- `packages/three-by-three/`, `packages/square-one/` - puzzle engines + three.js renderers. `packages/data/` - static JSON (CSP cases, presets).
- Aliases: `@/*` -> `apps/web/src/*`, `@convex/*` -> `packages/convex/*`.

## Setup
    nvm use        # Node version from .nvmrc
    npm ci

Works offline and needs no env for typecheck, lint, test, or build. Running the app needs a Convex backend - use the local one below.

## Verify a change (no network, no credentials)
    npm run typecheck    # Convex tsc + web tsc -b (covers packages/*)
    npm run web:lint     # ESLint, apps/web only
    npm test             # runs every tracked *.check.ts self-check
    npm run test:convex  # vitest + convex-test, in-memory Convex functions (auth, solves, ...)
    npm run web:build    # vite production build

CI (`.github/workflows/ci.yml`) runs typecheck, lint, `npm test`, and build on every PR and on pushes to main. `test:convex` is not in CI yet - run it yourself when touching `packages/convex/`.

Self-checks: `apps/web/src/lib/{algList,stats,cstimer}.check.ts`, `packages/square-one/src/cspScramble.check.ts`, `packages/three-by-three/src/old-pochmann.check.ts`. Changing puzzle/alg/stats logic: add an assert to the nearest `*.check.ts`, or a new `<name>.check.ts` next to the code in the same style (assert-based, throws on failure). `npm test` picks up any tracked `*.check.ts` automatically.

## Running the app locally (isolated, no login)
Each worktree can run its own local Convex backend. Only works when `.env.local` does not point at a cloud deployment (otherwise anonymous mode is ignored). See README "Local backend (isolated, no login)".

    CONVEX_AGENT_MODE=anonymous npx convex dev --once     # start local backend, push functions
    npx convex env set CONVEX_JWT_SECRET <any-value>      # once per local backend
    # set VITE_CONVEX_URL=http://127.0.0.1:3210 in apps/web/.env (use the port convex prints)
    CONVEX_AGENT_MODE=anonymous npm run dev

Ports 3210/6790 (backend) and 5173 (Vite) auto-increment, so parallel worktrees don't collide.

## Env
Copy from the committed `.env.example` files.
- `apps/web/.env`: `VITE_CONVEX_URL` (must match the deployment in root `.env.local`'s `CONVEX_DEPLOYMENT`, or the local backend URL).
- Convex deployment env: `CONVEX_JWT_SECRET` (HMAC key for auth tokens). Auth throws if unset - set it on every deployment, including local ones.
- None of these are needed for the verify steps above, including `test:convex`.

## Conventions
- Protected Convex functions take `token: v.string()` and call `await verifyToken(args.token)` first, throw on null. Mirror `packages/convex/solve.ts`.
- Auth state is global Zustand (`useAuthStore`), persisted to localStorage key `auth`. Don't add an AuthContext.
- Route guards live in `features/layout/RouteGuards.tsx`; `router.tsx` only defines routes.
- Tailwind classes inline; global styles in `apps/web/src/index.css`.
- Read `.agents/skills/convex/SKILL.md` before writing Convex code.

## Never
- Don't run `convex dev` or `npm run dev` against a cloud deployment, or `npm run convex:deploy`, unless asked - they push to shared remote deployments. Anonymous local mode (`CONVEX_AGENT_MODE=anonymous`, above) is fine.
- Don't edit `packages/convex/_generated/`.
- Don't commit `.env*` files (except `.env.example`).
- Don't push or commit unless asked.
